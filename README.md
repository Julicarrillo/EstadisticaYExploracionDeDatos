# 📊 Estadística y Exploración de Datos II

Repositorio de trabajos prácticos desarrollados en la materia **Estadística y Exploración de Datos II**, correspondiente a la Tecnicatura en Inteligencia Artificial y Ciencia de Datos.

El objetivo es aplicar herramientas estadísticas y modelos predictivos utilizando Python, combinando el análisis de datos, la interpretación de resultados y su aplicación en problemas prácticos.

## 📚 Trabajos prácticos

### 📌 Parcial 1 — Estadística Inferencial con Python

En este trabajo se aplicaron conceptos de estadística inferencial mediante ejercicios prácticos y simulaciones con Python.

**Contenidos abordados:**

- Teorema Central del Límite.
- Distribuciones muestrales y error estándar.
- Probabilidades teóricas y simuladas.
- Cálculo del tamaño muestral.
- Intervalos de confianza.
- Bootstrap y remuestreo.
- Pruebas de hipótesis y p-valor.
- Errores de Tipo I.
- Interpretación estadística para la toma de decisiones.

**Aprendizajes:**

Este trabajo permitió comprender cómo utilizar herramientas estadísticas para analizar la variabilidad de los datos, estimar parámetros poblacionales y evaluar hipótesis.

También permitió fortalecer la interpretación de resultados estadísticos y su aplicación en situaciones relacionadas con Ciencia de Datos e Inteligencia Artificial.

---

### 📌 Parcial 2 — Modelos de Regresión con Python

En este trabajo se aplicaron modelos de regresión para analizar relaciones entre variables y realizar predicciones sobre el rendimiento académico de estudiantes.

Se trabajó con un conjunto de datos que contiene información académica y personal de estudiantes, utilizando distintos modelos para estudiar su relación con las calificaciones y la probabilidad de aprobar una asignatura.

**Contenidos abordados:**

**1. Regresión Lineal Simple**
- Construcción de un modelo para predecir la nota final a partir de la participación en clase.
- Interpretación de los coeficientes de regresión.
- Análisis de correlación de Pearson.
- Predicción de valores.
- Visualización mediante gráficos de dispersión y rectas de regresión.

**2. Regresión Lineal Múltiple**
- Construcción de un modelo utilizando múltiples variables independientes.
- Interpretación de los coeficientes estimados.
- Análisis de la influencia de las variables.
- Verificación de supuestos: linealidad, normalidad de residuos y multicolinealidad.
- Predicción del rendimiento académico.

**3. Regresión Logística**
- Construcción de un modelo de clasificación binaria para predecir la aprobación de estudiantes.
- Interpretación de los coeficientes logísticos.
- Cálculo de probabilidades mediante `predict_proba()`.
- Análisis de las variables asociadas con la probabilidad de aprobar.

**Aprendizajes:**

Este trabajo permitió comprender las diferencias entre regresión lineal y regresión logística, interpretar los coeficientes de cada modelo y utilizar herramientas estadísticas para realizar predicciones.

También permitió reconocer la importancia de verificar los supuestos de los modelos y analizar sus resultados antes de obtener conclusiones.
