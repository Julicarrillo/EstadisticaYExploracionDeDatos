# EstadisticaYExploracionDeDatos
Aplicación de estadística inferencial, simulaciones, muestreo y pruebas de hipótesis con Python

Estadística Inferencial con Python 📊

Descripción

Trabajo práctico desarrollado en el marco de la materia Estadística y Exploración de Datos II, de la Tecnicatura en Inteligencia Artificial y Ciencia de Datos.

El objetivo es aplicar conceptos de estadística inferencial mediante ejercicios prácticos y simulaciones con Python, interpretando los resultados para comprender su utilidad en el análisis de datos y la toma de decisiones.

Contenidos abordados

Teorema Central del Límite.

Distribuciones muestrales y error estándar.

Probabilidades teóricas y simuladas.

Cálculo del tamaño muestral.

Intervalos de confianza.

Bootstrap y remuestreo.

Pruebas de hipótesis y p-valor.

Errores de Tipo I.

Interpretación estadística para la toma de decisiones.

Herramientas

Python

Google Colab

NumPy

SciPy

Matplotlib

Aprendizajes

Este trabajo permitió comprender cómo utilizar herramientas estadísticas para analizar la variabilidad de los datos, estimar parámetros poblacionales y evaluar hipótesis.

Además, permitió fortalecer la interpretación de resultados estadísticos y su aplicación en situaciones relacionadas con Ciencia de Datos e Inteligencia Artificial.

Nota

Trabajo realizado con fines académicos. Algunos ejercicios utilizan datos simulados.
